## Note on bulk binary upload
GitHub file API tools available here are text-oriented. Multi-MB PDF binaries are best added locally:

```bash
# from a machine with git access to jdnitrap/gasifier
cp ~/path/to/pdfs/*.pdf uploads/
git add uploads/
git commit -m "Add Gasifier Drive reference PDFs"
git push
```

Or use the GitHub web UI: repo → uploads → Add file → Upload files.
